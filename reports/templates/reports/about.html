About I-V Tree

Protecting Trees Through Community Action

I-V Tree helps communities record, protect and monitor trees affected by invasive ivy.

What is I-V Tree?

I-V Tree is a community conservation project designed to provide a simple way to report trees affected by invasive ivy and record how their condition changes over time.

Registered users can submit tree reports with a location, description and optional photograph. Members of the community can then add progress updates as a reported tree is protected and monitored.

Each progress update remains linked to its original tree report, creating a continuing record of activity and changes to the tree's condition.

How It Works

Report. Protect. Monitor.

Report

Record a tree affected by ivy with its location, description and an optional photograph.

Protect

Encourage responsible community action to support local trees and their surrounding environment.

Monitor

Add progress updates and follow changes to reported trees over time.

About the map

The map currently used by I-V Tree is a prototype visualisation of submitted tree reports. Marker positions are approximate and do not represent exact geographic locations.
